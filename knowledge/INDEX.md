# Índice de la base de conocimiento

Leer este archivo **antes** que cualquier ficha. Entrar siempre por el motor.

## Regla de entrada

1. Identificar **marca + generación + año**.
2. Buscar en la tabla el **código de motor** de ese año concreto.
3. Leer la ficha del motor. Ahí está el veredicto.
4. Leer la ficha del modelo solo para lo que no depende del motor
   (precio, carrocería, equipamiento, fallos de suspensión o electrónica).
